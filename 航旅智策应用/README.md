# 航旅智策 · 节假日旅游航线智慧营销 Demo

默认首页已重做为航空公司营销人员可操作的业务应用。以全量一万名模拟旅客训练模型，从需求热点、潜客名单、动态画像走到航线策略、本地模型生成创意、审核、模拟触达与后续行为复盘。

本机地址：[http://127.0.0.1:8765](http://127.0.0.1:8765)。旅客数据、模型推理和活动状态均在本机。服务监听127.0.0.1，不需要付费账号或API密钥。

## 换一台电脑准备完整Demo

下载仓库到D盘，安装Python3.11或以上后，双击仓库根目录的 `准备并启动Demo.cmd`，或执行 `./Prepare-Demo.ps1`。脚本自动安装项目虚拟环境依赖，从本仓库Release还原三份原始Excel、已训练需求模型及Qwen权重，校验SHA256并重建SQLite索引，无需重训。首次准备需联网，完成后可离线使用。

权重以Release分卷提供，自动下载、合并，数据和模型的完整清单见上级 `distribution/`。项目虚拟环境、pip缓存、临时文件和模型均跟随D盘项目路径，不创建新的C盘存储目录。已有Python安装仅作为解释器使用。

`./Prepare-Demo.ps1 -DataOnly` 可先准备数据和需求模型；完整文案生成仍需Windows x64、NVIDIA驱动和足够的本地内存/显存。GitHub用于文件分发，运行仍需本地Python服务与模型。

## 启动与停止

双击 `启动本地测试版.cmd`，或在PowerShell执行 `./Start-Local.ps1`。重复启动复用已有服务；后台运行，关闭浏览器不会停止。电脑重启后需再次启动，没有安装开机自启。

双击 `停止本地测试版.cmd`，或执行 `./Stop-Local.ps1`，停止本应用管理的网站与本地语言模型进程，保留数据。脚本核对进程路径和记录。网站默认8765端口，本地推理按需启动在8767端口。网站其他端口可用 `./Start-Local.ps1 -Port 8766`。

## 直接体验

1. **活动总览**：默认国庆场景，基于2024-09-30之前的全量行为，查看需求热点和区域分布。点击“新建营销活动”，填写活动名、假期、区域、目的地、人数和情景预算。
2. **需求洞察**：调整省份、客群、评分门槛及历史航班要求，重新计算。修改条件进入未保存预览，已有活动保存在“我的活动”。提前节日回放使用当时可用的历史规则，页面明确显示。
3. **潜客与画像**：搜索编号、城市、渠道，分页查看名单；点击画像查看关注变化、五类内容偏好、停留、重复访问、收藏及原始记录证据。可勾选保留部分旅客，冻结新名单版本，导出CSV。
4. **航线与策略**：按旅客原始常用出发城市匹配历史航班。日期取截点前明确计划；没有计划时使用标明的假期情景假设。日期、城市、已知预算精确匹配，不静默换日期或邻近机场；没有候选时明确显示。渠道与时段预测来自后续访问习惯，并遵守8—22时限制。
5. **创意工坊**：选择代表旅客和语气，本地Qwen实际生成新文案、配色与抽象插画主题，事实槽位按每位旅客合成。可以编辑标题、正文、配色和插画，导出SVG。勾选事实、历史价格和模拟属性三项核验后审核；编辑、名单变化使原审核失效。每份素材覆盖同目的地、同内容主题旅客，未覆盖部分保持待制作。
6. **渠道触达**：核对素材覆盖和名单，在确认框中执行本地模拟。退订旅客不进入名单；同一旅客同一情景日跨活动最多一次。记录可导出JSON，不向外部平台发消息，曝光、点击、订单保持未知。
7. **效果复盘**：回放完整未来7天行为，查看继续关注、机票查询和收藏代理标签，打开后续更新画像。训练集外指标、当前活动代理结果、原始营销漏斗分别展示；新触达不能与原始订单建立因果归因。

活动管理：点击右上角“我的活动”，找到活动后点“删除”，再点“确认删除”。删除后移入“已删除活动”，可以恢复；原始数据、模型、素材和模拟触达账本保留。删除当前活动会退出该活动，刷新后不会重新打开。

待审核素材删除：进入“创意工坊”，选择下方需要移除的“目的地 · 内容主题”素材，点击“删除待审核素材”并确认。素材从列表移除，活动、名单、其他素材和历史操作记录保留。已审核素材不能直接删除；旧名单版本中的待审核素材也可以删除。“目的地信息”是内容主题，删除素材不删除目的地数据。

旧旅客体验保留在 `/traveler/`，旧研究工具保留在 `/research/`。营销应用出发地来自一万名旅客的模拟字段；旧旅客端可选择历史表中的138个城市。

## 实际训练与评价

`runtime/models/marketing_models.joblib` 保存已训练权重；`training_report.json` 保存完整指标、时间协议、来源SHA256与标签定义。需求模型使用23个截点特征，不把合成偏好标签或未来行为作为输入。收藏按历史动作重建，访问与收藏按子事件时间遮蔽。

- 人口：10,000名原始模拟旅客、3,970,000条日过程、451对象、41目的地。
- 暖启动：2023年12月；训练：2024年1—6月每月15日，60,000个用户快照、2,460,000个用户目的地样本；验证：7—9月；冻结测试：10—12月。各阶段标签窗口完整且不跨阶段边界。
- 标签：截点后7天同目的地至少2次搜索过程（持续关注）；另训练至少1次机票查询、至少1次已发生收藏的辅助模型。全部是行为代理，不是购票概率。
- 模型：SGD逻辑回归、直方图梯度提升。只按验证集PR-AUC选模型、选F1阈值。标准化与五群MiniBatchKMeans只拟合训练快照；渠道与时段分类器也只拟合训练期。
- 所有10,000名既有旅客参与各阶段；结果不代表新用户泛化。每月15日的验证不代表已单独检验所有假期。
- 国庆截点晚于验证标签成熟时刻2024-09-22，可以使用所选模型；之前的假期回放采用历史基线，避免借用未来训练模型。

| 方法 | 冻结测试 Recall@3 | NDCG@3 |
| --- | --- | --- |
| 梯度提升（验证集选中） | 95.59% | 0.9386 |
| 逻辑回归 | 94.54% | 0.9277 |
| 近30天频次 | 94.01% | 0.9183 |
| 14天时间衰减 | 94.44% | 0.9226 |
| 最近一次关注 | 92.98% | 0.8448 |
| 固定6月30日画像 | 53.48% | 0.5151 |
| 训练集热门 | 7.49% | 0.0611 |

相同41个候选目的地、30,000个测试用户快照，29,998个存在相关目的地，2个无相关项单列。高分包含模拟数据的稳定习惯，不能据此宣称真实市场增益。渠道准确率97.42%、4小时时段准确率90.24%衡量访问习惯，不能解释为最优转化策略。

逻辑回归使用固定16轮计算预算；达到上限的辅助模型可能尚未收敛，详见报告。主需求模型为固定65轮梯度提升。没有真实座位、客座率、投放费用或满意度数据，不报告真实ROI或提升百分比。

## 本地生成模型

当前接入 **Qwen3.5-9B-Q4_K_M**，语言模型基于[官方Qwen3.5-9B](https://huggingface.co/Qwen/Qwen3.5-9B)，使用[Unsloth发布的GGUF量化权重](https://huggingface.co/unsloth/Qwen3.5-9B-GGUF)。固定量化仓库版本`3885219b6810b007914f3a7950a8d1b469d598a5`，文件5,680,522,464字节（约5.68GB），SHA256见`aigc_config.py`与`runtime/local_aigc/model_manifest.json`。这不是Qwen官方发布的GGUF文件；基础模型来自Qwen，量化发布者是Unsloth，遵循Apache-2.0许可。

使用固定llama.cpp b11565 CUDA13.4程序，GPU指定CUDA0，当前为RTX5070（12GB显存），8192上下文、单任务，关闭思考模式。当前NVIDIA驱动617.42支持CUDA13.4；迁移需要兼容该CUDA运行时的驱动。推理按模型自带Jinja聊天模板处理消息，限制JSON字段；错误模型、截断输出或无效JSON会拒绝保存，且不会静默切换回旧模型。权重未经本旅客数据微调，需求预测模型保持独立。

模型、CUDA程序、下载文件、推理日志均保存在本项目D盘目录。推理进程的TEMP/TMP、CUDA缓存及预留HF缓存也定向到runtime/local_aigc；网站临时目录为runtime/tmp，浏览器验收临时目录为runtime/browser-temp。不会为本次接入向C盘安装模型或CUDA工具包；启动脚本继续使用本机已有Python运行时。

旧Qwen2.5-1.5B文件和CPU程序仍保留在runtime/local_aigc中，供回退时人工配置；当前网站生成器使用9B。历史素材保留生成时的真实模型标识，不修改旧素材或旧审核记录。

语言模型生成文案、配色与抽象插画主题，本地SVG代码合成视觉。**不是扩散文生图或景点实拍**。日期、城市、航班号、历史价格由结构化事实槽位合成；没有公开攻略知识库RAG或实时旅游数据。风险提示不能完成语义事实核查，素材仍须审核。

模型首次生成按需加载；加载完成后复用显存中的模型。缺失时运行 `python setup_local_aigc.py`，下载固定版本量化权重和CUDA程序，支持断点续传，并对三个文件校验SHA256。下载不读取旅客数据，推理只访问127.0.0.1，不使用云端API、账号或密钥。

## 数据和运行目录

只读上一级`数据集/`原始文件，不覆盖Excel、指南和原分析报告：01_航班信息.xlsx共365,677条航班；02_用户行为.xlsx共10,000人和3,970,000日过程；03_营销反馈.xlsx共120,000触达、222,591事件、248模拟订单、82素材。

- runtime/aviation.sqlite3：全量索引；manifest.json：来源规模与指纹。
- runtime/models/：行为数组缓存、训练权重、报告和产物校验清单。
- runtime/marketing.sqlite3：活动、素材、审核与本地发送账本。
- runtime/local_aigc/：推理程序、模型、日志及进程记录。
- runtime/traveler.sqlite3、application.sqlite3：旧旅客与研究状态，相互独立。

本数据版本平均误点1—5分钟是指南明确的随机填补值，不用于真实可靠性排序。2024历史价格的采集时刻、税费、库存及跨午夜到达日期未知，不能作为当前可购票承诺。既有模拟营销反馈独立生成，不是新模型的实验结果。

## 迁移、复现和验收

需要Python3.11及以上；本机启动脚本优先使用Codex捆绑Python。运行网站不需要Node。迁移时保持应用与上级数据集目录关系：

```powershell
python -m pip install -r requirements.txt
python build_data.py
python marketing_ml.py
python setup_local_aigc.py
python server.py --port 8765
```

索引和模型已有缓存时无需重建或重训。重建索引前停止服务，再执行 `python build_data.py --rebuild`；来源变更须先核对数据契约与指纹白名单，不能直接套用本报告。

```powershell
python -m unittest test_core test_traveler test_marketing test_local_generation test_distribution -v
node --check web/marketing/app.js
python cleanup_marketing_test.py
node marketing_browser_check.cjs
python cleanup_marketing_test.py
```

43项后端测试使用真实数据及临时活动库，验证特征未来隔离、子事件遮蔽、标签窗口、模型产物、航班约束、审核、频控和后续评估。浏览器验收实际调用本地Qwen，检查七页流程、导出、刷新、移动布局、原始漏斗和审核失效。依赖Chrome及Playwright，脚本路径适用于本机。

浏览器验收创建名称精确为“闭环验收_国庆营销”的活动，清理脚本只删除报告明确记录的活动ID且核对名称，保留其他活动。结果与截图位于runtime/marketing-browser-results.json和marketing-*.png。重复验收前清理上次活动，避免正确的跨活动频控阻止本轮测试。旧入口可选验收脚本为traveler_browser_check.cjs、city_browser_check.cjs、browser_check.cjs。

本地Demo已实现模拟数据上的操作闭环；真实投放、实时库存、真实认证和业务增益验证需要后续独立接入。

活动删除专项验收：运行 `node campaign_delete_browser_check.cjs`，覆盖取消删除、删除其他活动、退出当前活动、恢复和移动布局，自动清理本次新建的两个测试活动。

素材删除专项验收：运行 `node creative_delete_browser_check.cjs`，覆盖取消、删除指定素材、刷新持久化、阻止删除后审批、移动端最后一条删除及名单保留。只创建并清理名称精确为“素材删除专项验收”的本次测试活动。全部临时文件与截图位于项目的runtime目录。
