# 实验记录约定

> 2026-10-12 更新：本文保留框架阶段的设计约定；可运行实现已同步至 `航旅智策应用/`，当前功能、启动方法与完成状态以仓库首页及应用 README 为准。数据仍为历史航班与模拟旅客，不代表真实业务效果。

当前未训练模型或产生模型成绩。每次实验保存experiment_id、目标、数据与知识版本、切分日期、候选集、算法配置、种子、指标定义、样本量、失败样例、耗时成本及data_kind。

按预测、画像、推荐、策略、RAG、文案视觉分别登记。统一测试集和预算后才能比较模型。合成实验与公开聚合研究结果分表；真实业务效果需要相应标签或对照证据。完整口径见[评估层](../docs/evaluation.md)。
