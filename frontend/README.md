# 浏览器前端实施约定

> 2026-10-12 更新：本文保留框架阶段的设计约定；可运行实现已同步至 `航旅智策应用/`，当前功能、启动方法与完成状态以仓库首页及应用 README 为准。数据仍为历史航班与模拟旅客，不代表真实业务效果。

当前为页面规格入口，没有已实现的可交互平台。页面顺序为需求看板、画像、航线推荐、营销策略、内容工坊、活动反馈和评估对比，详见[应用层](../docs/application.md)。

全局保存场景、假期、客源区域和截点；修改条件后清除或标记过期结果。页面必须展示来源、统计时间、合成属性和缺失状态；导出保留这些信息。状态包括加载、空数据、失败、无权限和待重算，避免伪造指标图表。
