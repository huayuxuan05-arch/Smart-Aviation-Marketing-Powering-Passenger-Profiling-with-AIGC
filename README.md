# 华翼朝阳 · 个性化旅游定制

本机已显式接入现有Qwen3-4B，以AMD Vulkan运行；个人页整套旅行卡片由本地模型整理，航班由工具按用户自主选择的标签实时查询。公开启动参数仍支持模板模式；用 Start-Local.ps1 -GenerationMode local-model 启用模型，若存在本机active_model.json则复用指定本地权重，未配置时使用原Qwen3.5-9B下载配置。

## 两个使用入口

| 入口 | 地址 | 当前功能 |
| --- | --- | --- |
| 个人旅客 | `/personal/` | 自主选择航司、日期、预算等标签，本地模型整理旅行方案，可自愿匿名共享动态画像 |
| 营销人员 | `/marketing/#trips` | 处理已同意共享的真实旅客，分析意向、近期热门目的地、已保存方案及决策名单 |

首页 `/` 选择入口。个人端注册并登录独立账号，按固定用户编号保存偏好版本、历史方案与本站浏览操作；更换浏览器后登录同一账号可继续使用，退出并切换账号不混用资料。旧匿名会话保留，不自动并入新账号。日期、天数、预算未确定时可仅保存意向；确定出游后支持2至8天、具体景点、住宿侧重、日期弹性、备选许可和超预算处理。

个人端新增文字需求协商：输入旅行想法或对当前方案的意见，先生成草稿、追问缺失条件，调用既有航线与预算工具展示预览及费用差异，逐项确认后保存新方案和偏好版本。节假日日期、多人总预算及往返机票金额不自动猜测或折算。默认使用明确标注的本地规则解析，不调用大模型；显式启用本地模型时，可由Qwen提供结构化槽位建议，仍由程序核验、本人确认。规则解析仅覆盖受支持的表达，未识别需求可使用表单。详见[应用与确认边界](docs/application.md)。

正式营销端需要独立管理账号，保留既有八个导航，不新增页面。个人页开启匿名共享后，确认偏好、模块浏览、目的地选择、草稿提交、方案导出及航班交互成为有时间戳的证据；不记录输入过程或站外浏览。营销端汇总兴趣、同行、住宿、预算、日期弹性、航司和浏览操作，支持筛选、10/20/50条分页、批量选择和匿名案例JSON导出。用户没有匹配航班时仍保留所有航司偏好，网络失败不作为无航班证据。关闭共享后从当前画像、热门榜和决策名单移除；已下载的离线导出不能自动撤回。窗口为7/30/90天，每30秒同步，限本站客群。模拟用户和隔离验收数据不自动成为真实客群。

界面使用直接功能名称，去除宣传式步骤说明、画像截至和规划范围公共栏。问卷只作后台补充，收集工具与空白问卷保留，不在网站单独设置统计页或导航入口。原始答卷、整理后逐人数据和个人方案不提交仓库。

## 本地运行

1. 下载或克隆本仓库，解压至D盘，安装Python 3.11或以上。
2. 双击根目录的“准备并启动Demo.cmd”。
3. 自动下载、校验并恢复原有数据与模型后，访问 `http://127.0.0.1:8765/`。

现有[发布资产](https://github.com/huayuxuan05-arch/Smart-Aviation-Marketing-Powering-Passenger-Profiling-with-AIGC/releases/tag/demo-2026-10-12)提供三份模拟/历史原始Excel、需求模型和Qwen3.5-9B量化权重；最新网站源码以本仓库主分支为准。完整本地语言模型推理使用Windows x64与NVIDIA CUDA；仅准备网站数据时，在应用目录运行 `./Prepare-Demo.ps1 -DataOnly`。

后续通过应用目录中的“启动本地测试版.cmd”和“停止本地测试版.cmd”管理服务。网站无需云端模型密钥，不调用收费模型或真实营销平台。详见[应用使用说明](航旅智策应用/README.md)。

首次启动会在忽略提交的 `航旅智策应用/runtime/marketing-admin.txt` 生成随机管理账号密码。参与者在个人入口自行注册，管理员在营销入口登录；密码仅保存独立盐值与PBKDF2摘要，登录令牌摘要在12小时后过期，退出会撤销会话。数据库为 `runtime/personal.sqlite3`，使用WAL及归属索引。该版本仍只监听127.0.0.1，可供本机轮流使用；没有发布成外网网站，也未证明200人同时推理能力。

## 数据与模型

- 原模拟行为模型使用3,970,000条过程记录、10,000名旅客、41个目的地，按时间划分训练、验证和冻结测试。
- 营销候选先满足历史产品条件，再按名单配额选择；同次行程预算、原始航班日期、素材审核、业务资格、退订与跨活动频控分别核验。
- 本地Qwen解释已有结构化事实，生成可编辑建议、文案及SVG海报；没有用真实答卷微调Qwen权重。
- 问卷导入与偏好模型独立保存。最新人工整理版模型未超过热门基线，保留为对照；线上采用主动偏好、预算与航线约束，样本热度只作并列参考。
- 没有真实购票、实时库存、真实渠道授权和因果增益标签，不报告实际收入或转化提升。

真实问卷属于可选私有补充；其他使用者未导入问卷时，网站仍按用户主动选择与既有规则运行。问卷同意研究与复访不等于营销授权。方法和汇总结果见[问卷补充与验证](docs/survey-evidence.md)。

## 验证

```powershell
python scripts/validate_framework.py
python scripts/validate_dataset.py
cd 航旅智策应用
python -m unittest test_core test_marketing test_decisions test_travel_planner test_personal test_personal_assistant test_survey_evidence test_local_generation test_content_generation test_distribution -v
node entry_browser_check.cjs
node travel_browser_check.cjs
node decision_browser_check.cjs
```

先还原数据与模型再执行完整业务检查。三个浏览器脚本顺序执行，各自使用8769隔离服务与临时活动库，需要Chrome及Playwright；脚本支持本机运行时路径，未把无数据CI当作业务验收。

本次需求协商优化在本机原始数据与训练产物上通过113项后端检查（含22项需求协商专项）、22项入口与协商浏览器检查，五层框架及数据清单校验通过。浏览器结果存于本机runtime/tmp/entry-qa/checks.json。未启动大模型，结构化提取适配器仅完成模拟协议测试，没有真实推理质量评估。

此前入口更新的87项后端及相关浏览器验收记录见[已有更新验收](experiments/results/local-demo-2026-10-15/README.md)，不作为本次新增功能的实测结果。
