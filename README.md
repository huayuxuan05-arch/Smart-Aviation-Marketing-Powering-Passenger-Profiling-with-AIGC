# 航旅数字画像与AIGC智慧营销参赛框架

第四届（2026）中国研究生企业管理创新大赛 · 数字技术应用专项 · 钻石命题2（东航研发—航旅数字画像）。

**当前只搭建整体思路框架并提供Word实施指南，不继续扩展系统。** 主线使用公开聚合信息和沙盒数据，不以取得企业真实旅客数据为前提。先读 [项目怎么做](docs/project-plan.md)，或下载 [Word实施指南 共12页](deliverables/航旅数字画像项目实施指南.docx)。

## 研究主线

**公开需求信号 → 需求识别 → 市场客群与沙盒画像 → 航空产品匹配 → AIGC内容设计 → 渠道与推送时机 → 效果反馈。**

公开搜索指数、攻略热度和旅游统计用于地区、节日及目的地需求研究；沙盒用于个人画像和流程验证。聚合热度不能识别真实旅客、证明个人购票意向或提供营销授权。补充攻略提出企业不提供真实数据，本框架按此前提安排。

## 怎么做

| 阶段 | 主要工作 | 交付物 |
|---|---|---|
| 1 界定问题 | 选一个节日 一个客源区域 三至五个目的地 | 一页定义与研究问题 |
| 2 数据调研 | 核查公开来源 可得性 口径 用途与时间 | 来源台账 需求面板 沙盒说明 |
| 3 方法设计 | 趋势识别 标签 分群 产品筛选排序 | 画像方法 推荐策略与解释 |
| 4 内容渠道 | 产品事实 AIGC提示 人审 渠道和时机 | 内容样例 运营流程与护栏 |
| 5 验证价值 | 规则对照 回测 盲评 财务情景 | 证据台账 管理建议及效益模型 |
| 6 报告展示 | 官方模板 匿名核查 可选原型 | Word/PDF报告与展示方案 |

当前没有真实业务效果，模拟转化率不能写成企业提升成果。

## 参赛与来源边界

原始命题PDF第2—3页确定场景与闭环，官方模板确定报告章节、匿名和文件要求。补充攻略关于外部个人行为可获取性、企业解读和赛程仍需原始资料复核。

模板要求封面有项目与团队名称，不出现成员、学校、导师身份；Word/PDF同时提交，文件名`命题2_团队名称`，正文建议10000—15000字。评分细则与正式赛程待核对，不猜权重和日期。本指南不是最终参赛报告。
