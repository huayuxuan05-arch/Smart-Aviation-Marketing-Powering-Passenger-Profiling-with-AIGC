# 五分钟Demo脚本（建议4分30秒）

录制前使用新数据库启动，例如 `python -m app.server --database runtime/recording-01.sqlite3`，打开浏览器本地地址。录制结束自行检查时长和文件体积；当前仓库未生成视频。

| 时间 | 画面与操作 | 讲述重点 |
|---|---|---|
| 0:00—0:35 | 首页与需求洞察 | 节假日需求变化、未购票潜在人群难识别；明确合成数据/离线模板 |
| 0:35—1:20 | 分群、目的地关注、选择SYN-0002 | 30天窗口与兴趣衰减；画像时间戳、解释、出发地与预算 |
| 1:20—2:00 | 推荐理由与渠道时机 | 供给约束、可触达门槛、授权和频控；当前渠道和时段是规则建议 |
| 2:00—2:50 | 点击生成文案与视觉草稿 | 展示个性化文案及SVG；说明真实LLM/图像模型尚未接入，未来用产品知识约束 |
| 2:50—3:35 | 审核通过，再模拟触达 | 演示人审状态与发送前复核；真实发送数为0，频控余额随模拟变化 |
| 3:35—4:05 | 效果评估与审计 | 随机分组统计管线，但概率人为设定；不作为真实提升证据 |
| 4:05—4:30 | 架构/路线与业务价值 | 企业授权数据→模型/知识→真实渠道→受控实验；用贡献毛利和成本验证ROI |

## 必须准确讲述

- 120位旅客及4条示例航线均为合成；票价不代表真实促销。
- 画像方法支持按截点更新，当前数据截点固定，无实时采集。
- 内容来自离线模板；SVG是模板视觉，不是图像模型输出。
- 模拟指标不代表实际转化、客座率或满意度，也没有真实消息发出。
- 当前审核只记状态，企业身份、权限和渠道执行属于下一阶段。

## 建议答辩准备

为什么不用复杂模型？当前缺授权数据，先用可解释规则验证闭环，真实标签到位后做时间切分对照。如何保护隐私？用途/渠道授权、最小化标签、身份映射隔离、发送前撤回复核。如何证明效果？用户固定随机组、预注册窗口/样本量/护栏、转化差区间和净收益，而非仅展示点击数。
