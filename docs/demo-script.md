# 未来平台演示与验收脚本

这是待实现平台的演示路径，当前不声称已有可运行Demo。建议约五分钟，以一个场景贯穿七页面。

| 时间 | 演示动作 | 验收重点 |
|---|---|---|
| 0:00—0:40 | 选择2025国庆中秋、上海及三目的地 | 假期、数据覆盖、来源与截点 |
| 0:40—1:20 | 查看需求与合成客群画像 | 聚合与个人模拟区分，标签可解释 |
| 1:20—2:00 | 查看上海—成都规划候选 | 热门与供给证据，缺失价格可见 |
| 2:00—2:40 | 设预算、渠道与发送时机 | 约束、参数假设、策略对照 |
| 2:40—3:40 | 检索知识，生成文案及视觉 | 引用、生成方式、事实与人工审核 |
| 3:40—4:20 | 模拟活动，再重复一次请求 | 合成标识、幂等、停止机制 |
| 4:20—5:00 | 查看评估和模型对比 | 样本、切分、未评估项、真实效果边界 |

补充检查无匹配航线、空画像、知识过期、生成失败和内容修改后重新审核。报告中的功能截图只在对应功能实现后产生；界面设计图须标明设计稿。
