# 应用层页面与交互

平台面向航空营销人员。以一个节日营销任务为入口，贯穿需求观察、画像、推荐、策略、内容、审核和复盘。采用浏览器界面与Python后端；本文件定义待开发行为，不代表页面已上线。

## 页面清单

| 页面 | 用户操作 | 展示与输出 |
|---|---|---|
| 节假日需求看板 | 选假期、客源地、目的地、数据截点 | 数据覆盖、观察／预测、来源、时间曲线；无日序列不造曲线 |
| 客群画像工作台 | 选客群或合成旅客、调整截点 | 主题、近期变化、证据、置信度与合成标识 |
| 航线推荐 | 选客群、出行日期、预算情景 | 候选、约束、推荐理由、价格日期、未知项 |
| 营销策略 | 调整预算、渠道、时机、频控 | 方案比较、假设、成本构成及审核状态 |
| AIGC内容工坊 | 查看知识引用、生成文案与视觉 | 来源卡、草稿、生成方式、版本、审核意见 |
| 活动与反馈 | 保存方案、审核、模拟执行 | 活动状态、模拟事件、反馈漏斗、归因窗口 |
| 评估与模型对比 | 选择同一实验内的不同模型 | 误差、推荐指标、内容质量、样本量及失败案例 |

## 核心操作路径

建立“2025国庆中秋／上海／成都三亚昆明”场景，查看数据覆盖，选择客群，取得规划航线候选，设置渠道和时机，检索产品知识，生成并审核内容，运行一次模拟活动，再进入评估页。每一步保留场景、数据和内容版本；前一步改变后，下游结果标为待重算。

## 必须可见的状态

公开聚合、真实授权与合成数据分别标识；“来源发表于何时”和“数据统计哪一天”分开展示。预测没有训练条件时显示“数据不足”，不能把观测值冒充预测。知识缺失时列出缺项；没有实时库存时显示“规划推荐”；没有模型接入时显示模板模式。

活动状态：草稿→待审核→已审核→模拟执行→完成／停止。修改已审核内容后回到待审核；停止后不再生成后续模拟触达。真实发送不在当前范围，界面按钮明确写“模拟执行”。

## 验收场景

同一场景可完整走完链路；修改目的地会更新候选与引用；无航线、无价格、空画像、知识过期、模型失败均有可理解的提示；模拟执行重复请求不会重复生成同一事件。导出活动方案时保留来源与数据属性，不把未评估指标显示为零。
