# 当前30,000人需求预测验收（2026-10-17）

已取消Qwen语言模型微调，以下训练仅针对需求预测。原始工作簿与冻结基线模型的SHA256保持不变。使用26,000名开发用户、2,000名验证用户和2,000名独立测试用户；各用户按年度相对截点构造历史特征与后7天标签。特征只到当天末尾，训练最后截点后7天早于验证首截点。详见[人口划分](current-cohorts-2026-10-16.md)。

训练比较六项近期关注特征与全23项特征的梯度提升模型，并在验证集上选择模型及与近期规则的混合权重。采用NDCG@3为选择指标，Recall@3下降不得超过0.005。保存selection.json后才读取测试标签；测试不再用于调参。

| 方法（同一2,000人、6,000快照） | NDCG@3 | Recall@3 | PR-AUC |
| --- | ---: | ---: | ---: |
| 原2024冻结模型 | 0.9105 | 0.9212 | 0.9012 |
| 验证集最强规则：14天衰减 | 0.9122 | 0.9252 | 0.9132 |
| 验证选定新模型：近期特征梯度提升 | 0.9129 | 0.9246 | 0.9179 |

6,000快照中5,419个有相关目的地、581个无相关目的地，后者单列，不从总体覆盖率中悄悄删除。按用户聚类的500次配对Bootstrap，新模型相对14天衰减的NDCG均值差为0.000015，95%区间为[-0.001814, 0.002151]，包含0；相对原模型区间也包含0。因此候选保留为对照，**未晋升、未替换线上冻结模型**。表内快照均值与Bootstrap用户均值的权重不同，不能混为同一统计量。

广泛探索组的Recall@3约0.0688、NDCG@3约0.0493，明显低于稳定关注组，说明未来随机探索信号有限。系统仍以本人主动确认的偏好作决定，不靠模型猜测放宽航司、日期或预算。现场首次使用者没有长期历史，不能伪造需求概率；本次评估也不证明真实购买、满意度或营销增益。

可复查的本机产物位于runtime/demand-models/demand-30000-20261017-v1：selection.json、report.json和model.joblib。模型仅CPU训练，不占用语言模型微调显存；网页Qwen独立推理。已封存测试，继续优化须预先定义新协议与独立评价方式，不能反复看同一测试集挑结果。

以下保留原冻结模型及历史实验记录，不能当作本次30,000人的指标。

新增10000名模拟用户的网站业务回放。人口复用原10000名用户，出发地取原始字段；共享、主题填写、规划及保存使用固定随机种子和明示场景概率。这些比例不是实测接受度，模拟共享也不是真实同意。批量方案走模板，查询联网禁用；后补仿真航班目录与原查询结果分开，不生成评分、订单或经营收益。营销素材实际调用本地Qwen，审核路径自动回放，不构成人工盲评。

预测以2024-09-24虚拟截点冻结，仅随后导入原模拟未来7天，目标为至少两个不同日期关注同一目的地。按所选模拟活动单列相关样本和无相关项样本；Recall@3不能当作全体万人准确率、独立新用户测试或新文案效果。整个回放不属于万人并发验收。
