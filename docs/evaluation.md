# 当前方法验证与证据计划

## 不依赖企业订单的评估

| 对象 | 方法 | 能支持的结论 |
|---|---|---|
| 公开需求信号 | 历史节日回测 热点一致性 来源交叉检查 | 市场信号的及时性和稳定性 |
| 客群标签 | 规则解释 样例审阅 阈值与权重敏感性 | 标签合理性和运营可用性 |
| 产品匹配 | 统一热门基线 约束检查 无产品案例 | 匹配方法与解释可行性 |
| 内容质量 | 模板对照 人工盲评 事实核查 | 相关性 品牌 事实与成本 |
| 沙盒流程 | 审核 授权 频控 撤回 重复执行 | 工程流程是否有效 |
| 经济效益 | 明示参数的保守/基准/乐观情景 | 盈亏平衡与待验证价值 |

没有真实购票标签时，不计算或宣称真实旅客预测准确率。聚合回测评价的是市场信号，不能替代个人购票验证。

## 设计对照与消融

需求对照静态热门榜；推荐对照统一热门航线；内容对照统一模板。分别移除时间衰减、主题因素、预算情景、个性化内容，解释各模块作用。记录样本、时间、参数、方法及失败案例，不只选展示效果好的样例。

## 证据台账

每项结论记录evidence_id、claim、source_id、period、method、version、scope、is_synthetic、limitations、report_section。区分命题痛点、补充资料前提、研究假设、市场代理结果、沙盒结果及真实实验。

当前没有真实客座率、满意度、转化或成本改善证据。随机概率合成的差值不支持因果提升结论。后续若取得企业试点条件，再按[真实实验参考](reference/enterprise-evaluation.md)固定用户随机分组、预注册归因和护栏，报告区间。
