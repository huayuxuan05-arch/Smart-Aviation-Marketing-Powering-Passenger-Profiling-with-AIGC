# 评估层协议

评估覆盖预测误差、推荐效果、营销反馈和模型对比，同时检查RAG及生成内容质量。每份结果记录实验ID、目标、数据版本、时间切分、模型配置、随机种子、样本量、缺失率和证据等级。

## 指标与适用条件

| 对象 | 指标 | 前提与解释 |
|---|---|---|
| 需求预测 | MAE、RMSE、WAPE | 同粒度真实目标；目标绝对值之和为零时WAPE不计算 |
| 动态画像 | 标签覆盖、稳定性、更新及时性、事件解释 | 带时间事件；无真实标签不宣称画像准确率 |
| 航线推荐 | Recall@K、NDCG@K、候选覆盖、约束违规率 | 有相关性或选择标签；仅规则审阅时只报覆盖和约束 |
| 营销反馈 | 点击率、购票转化率、退订率、单次转化成本 | 分母、去重和窗口先定义；合成结果只验证流程 |
| RAG与内容 | 检索相关性、引用正确率、事实支持率、人工盲评 | 固定知识版本、问题集与评分规则 |
| 模型对比 | 上述指标及耗时、成本、参数规模 | 同数据、同切分、同候选集和同评估预算 |

MAE为绝对误差均值，RMSE为平方误差均值的平方根，WAPE为绝对误差之和除以实际值绝对值之和。平台指数模型只评价指数预测，不能改称航空客流预测。标签或样本不足时填“未评估／不适用”，不能填0冒充测量。

## 数据切分

按时间划分训练、验证和测试，优先跨假期滚动回测。训练集拟合清洗与归一化，验证集选择参数，测试集仅作最终比较。特征与RAG知识都受决策截点约束。2025国庆历史案例截点为9月30日，10月9日发布的实绩不能用作其节前输入。

## 对照与消融

预测比较历史基线、线性与树模型；画像比较静态和动态；推荐比较热门榜、规则与具备条件后的排序模型；策略比较固定方案、规则方案和具备条件后的约束优化；内容比较模板、无检索生成和RAG生成。分别移除时间衰减、需求信号、预算因素或检索，记录变化与失败案例。

## 营销反馈口径

先固定曝光、送达、点击、订单与退订的定义。点击率采用同一活动窗口内去重点击人数／去重有效曝光人数；转化率以预先指定的分配人群或有效曝光人群为分母，不混报。订单按order_id去重，归因窗口、退款处理及跨渠道冲突提前记录。没有真实订单时只报告合成流程结果。

## 业务结论

公开聚合分析、合成演示、真实观察与随机实验分别呈现。模型误差下降不自动证明营销收入增加；真实增量需要对照试验和一致的收益成本口径。报告列出均值、分组结果、样本量和不确定性，不预设漂亮的提升比例。
