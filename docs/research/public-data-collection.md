# 如何继续找外部公开数据

先定义每个字段要回答的问题，再找来源。不要先下载大量异质数据再拼成旅客画像。已取得的具体证据见[首轮调研](2025-national-day-first-round.md)。

## 按问题选择入口

| 问题 | 优先入口 | 操作与记录 |
|---|---|---|
| 假期日期是什么 | 国务院官网 | 检索2025年节假日安排，记录公告发布日期及假期长度 |
| 节前是否有旅游兴趣变化 | [百度指数](https://index.baidu.com/)等平台公开指数 | 按正常账号流程查询；核查地域、时间、关键词和可导出范围；保存平台允许的导出，不调用未授权接口 |
| 实际旅游规模如何 | [文化和旅游部](https://www.mct.gov.cn/)、城市文旅局及统计局 | 历史新闻、统计分析、政府信息公开栏目按年月翻页；选城市同时间同对象统计 |
| 成都的省级背景如何 | [四川文旅厅](https://wlt.sc.gov.cn/) | 文旅要闻历史分页定位2025年10月；省级数据单列，不能填入成都市字段 |
| 三亚背景如何 | [三亚市政府](https://www.sanya.gov.cn/) | 优先统计分析；年度过夜游客与节日游客分开记录 |
| 有什么航空产品可推荐 | [东航官网](https://www.ceair.com/) | 人工核对产品名称、规则、目的地、有效期、适用限制；若网页动态或不可导出，保留带时间的人工核验记录 |

以上是检索入口，不表示每个入口已提供所需字段。搜索引擎可用组合词：`成都 2025 国庆 中秋 接待游客 10月8日`，或加`site:政府域名`。搜索摘要只是线索，必须打开原发布页核对。原站失败时可找官方转载，但要保留原机构和转载关系。

## 已遇到的访问限制

本轮昆明相关官网HTTPS读取出现证书校验失败，成都部分门户返回HTTP 412；不关闭证书校验、不绕过访问限制。搜索引擎还出现验证页或不相关结果，因此未用其摘要作为数值证据。百度指数自动访问未取得可核验导出，仍需按平台正常流程人工查询。

这些是本次访问结果，不证明网站长期不可用。可以在浏览器中通过用户已配置代理复查、查找同一机构其他官方栏目或联系平台支持。找不到数据时记录“未获取”，无需等待它才继续已取得资料的研究。

## 每次采集的最小记录

来源标题、发布机构、原链接、发布日期、获取时间；地域范围、客源区域、观测起止日期、统计对象、数值、单位、同比比较对象；估算或实测、公开与派生、使用许可/条款、缺失原因。地区未知保留unknown，数值未知留空；不把搜索指数、租车订单、游客人次和航班旅客量视为同一种指标。

日指数导出用[空白模板](../../data/public/search_index_template.csv)。同一次研究使用同一指数类型、时间粒度和地域过滤；分别保存关键词定义与平台说明。无法获得历史导出可改为从现在开始前瞻采集，但要同步修改研究日期，不能填回历史。

## 可复用脚本

在仓库根目录执行，脚本继承`HTTPS_PROXY`或`https_proxy`；未配置会拒绝联网，不打印代理端点或凭据：

```powershell
python scripts/research_public_sources.py https://www.mct.gov.cn/whzx/whyw/202510/t20251009_962532.htm --keywords 国庆
python scripts/validate_public_data.py
```

抓取器只读取明确指定的HTTPS页面，保留TLS校验，阻止HTTP降级跳转，不自动遍历站点。自动抓取前核对网站使用条款及访问要求；对于登录、验证码或平台授权接口使用正常人工流程。不要上传完整网页正文、个人资料、Cookie、Token或账号密码。

`prepare_research_deliverables.py`是本轮人工选定事实的整理脚本，需要本地核验缓存；它不会从新网页自动识别和接受数字。后续新增来源须先人工核对正文，再扩展台账及事实，最后运行校验。GitHub仅保存可复核的事实和来源，沙盒另行标注。
