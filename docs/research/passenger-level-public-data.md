# 旅客层面的出行、消费和偏好公开数据选型

核验日期：2026-10-04。依据命题PDF第2—3页对出行意向、价格、目的地兴趣、动态画像与营销闭环的要求进行选型。附件确定研究问题，数据获取与使用仍按各发布源规定执行。

这轮查找取得了可下载的个人调查、用户评分和匿名预订记录。它们可以支持画像方法研究，但地域、记录粒度和授权不同。未找到经本轮核验、可直接公开下载、同时具有中国航空旅客长期出行、实际消费、浏览偏好三类字段的一体化真实数据。

## 怎样覆盖三类画像信息

### 出行：先用NHTS的飞机子样本

官方长途表`ldtv2pub.csv`每个家庭—个人组合一条，包含最近一次长途出行与部分频次信息，并非多条航空历史订单。

- 关联键：`HOUSEID + PERSONID`，可关联个人表`perv2pub.csv`；家庭属性按`HOUSEID`关联`hhv2pub.csv`。只能在同一NHTS版本内部关联。
- 官方代码表中`MAINMODE=14`表示最近一次长途出行主要方式为飞机，本轮文件筛得1,713人。
- 可用字段：`FARREAS`（商务、个人度假、探亲访友等目的）、`LONGDIST`（过去30天长途次数）、`NTSAWAY`（离家住宿夜数）、`LD_NUMONTRP`（同行人数）与距离、年龄、收入档位。
- `LD_AMT`表示过去一年Amtrak使用次数，不能按名称误当消费金额。`HHFAMINC`是家庭收入类别。负值跳答、未知、拒答等必须按代码表处理。
- 推断美国总体分布时使用对应调查权重，并说明抽样设计；1,713人的简单占比只能叫样本分布，不能当中国航空旅客比例。

用途：研究商务/度假/探亲场景的出行特征，设计可解释的场景标签，再由报告讨论向国内业务迁移的条件。

### 消费：酒店价格与航空票价分别研究

酒店镜像比原始31个变量多一个`hotel`标识列，行数与论文两酒店40,060 + 79,330一致。论文已说明每行代表预订，删除客户身份，故不能计算每位旅客的跨次消费RFM。

重点字段：`adr`、两类住宿夜数、`adults/children/babies`、`market_segment`、`distribution_channel`、`reserved_room_type`、`meal`、`is_canceled`。这些可支持预算档位与同行场景研究。

`adr × (stays_in_weekend_nights + stays_in_week_nights)`至多作为预订住宿金额的近似代理，须核查取消、零夜数、房间数、异常价格和交易口径；不能称为实际到账收入、每人消费或旅行总预算。`is_repeated_guest`仅是历史标志，不提供可追踪ID。

DB1BTicket官方字段把`ItinFare`定义为每人行程票价，`Passengers`为旅客数，`ItinID`为行程编号；[字段原页](https://www.transtats.bts.gov/Fields.asp?gnoyr_VQ=FKF)。用来研究票价、距离、往返等关系时，还要检查票价可信度与批量票标志、样本覆盖及年份。没有个人随时间的连续记录。

### 偏好：先用小而可复核的UCI评分

P03适合作为首个偏好聚类数据：本轮检查980行均11列，无空单元格。类别名称按UCI字典映射，分数是类别平均评价；不是搜索兴趣、到访频次或支付意愿。

P04更大，但下载文件实际为26列，其中末列标题为空；24类评分中共发现3个不能直接转数值的单元格（含空值）、末列2行非空，且存在0评分。页面称无缺失、评分1—5，与文件情况并不完全一致。必须记录空值、非数值、尾列和0的含义，再决定修复或剔除；本轮未擅自修复，也不把0自动解释为不喜欢。

满意度数据适合服务体验分析：低评分可能来自某次服务体验，不能直接当成长期偏好。Maven公开预览有年龄、舱等、商务/个人出行与多个服务评分，但真实来源未完整确认、缺少金额，适合作为补充基准。

## 本项目的采用建议

1. **实证方法研究**：NHTS飞机子样本研究出行场景；酒店预订研究价格与同行结构；UCI 484研究类别评分与分群。分别建模和报告结果，不把不同来源的用户ID拼成同一个人。
2. **动态画像演示**：采用明确标注的航空会员虚构数据或现有沙盒，展示月度行为更新、会员价值标签和内容生成。P07公开字典把CLV解释为累计航班发票价值，但仍是虚构值；全历史CLV也不能直接用于较早月份预测，以免使用未来信息。当前飞行活动预览仅8列，与字典列举的部分航班字段不完全一致，完整文件到手后要再核对。
3. **国内节假日场景**：继续使用[首轮官方市场资料](2025-national-day-first-round.md)确定目的地和节日背景。公开国外微观样本用于方法验证，结论不直接外推为东航客户特征。
4. **赛题中的购前兴趣**：上述优先样本未提供同一旅客跨平台搜索、访问、关注及营销授权。若需验证购前意向，另做自愿问卷/实验并取得相应授权，或将该部分限定为沙盒验证。
