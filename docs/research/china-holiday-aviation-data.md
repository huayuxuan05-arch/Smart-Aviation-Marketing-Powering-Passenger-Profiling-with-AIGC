# 中国节假日航空数据：2025年国庆中秋专项

核验日期：2026-10-08。按当前优先级，研究中国节假日的航线、预订、票价和机场客流。主案例沿用2025年10月1—8日，上海客源区域，成都、三亚、昆明目的地。本轮新增10个正文已核验来源，并复用首轮假日安排及文旅需求证据。

**已经找到中国节假日的真实公开聚合数据，也找到涉及上海—成都的航线证据；尚未取得三个目标城市对的完整逐日销量、历史票价和个人浏览—购买记录。** 下列材料主要是官方发布、机场信息及平台统计的新闻报道，不是可下载的全量旅客数据库。

## 4. 如何进入项目分析

1. **节前选候选。** 以2025-09-30结束为历史决策截点，使用H04、H06、H08、H09和S02。保留发表时间、观察截止日、预计出行时间；三者含义不同。
2. **先做可解释比较。** 将“热门名单成员”“已公布增加运力”“目的地主题契合”分别作为证据。缺失不填0，不把新闻条数当成真实客流；规则权重属于团队假设。
3. **节后作有限核对。** H01—H03、H05、H07、H10是事后材料。可核对假期市场方向、机场预测与实绩；不能用机场总量验证上海出发的航线推荐准确率，更不能声称提高了转化率。
4. **补齐训练数据。** 优先申请或取得平台允许导出的“出发城市×目的地×出行日×查询日”机票价格／搜索趋势。单个假期的几十条汇总事实不足以训练和验证可靠的复杂预测模型。需要跨多个假期、同口径日序列，再作时间留出评估。

价格要同时记录含税与否、币种、单程／往返、最低价／均价、查询日和出行日。H09的819元是节前裸价监测，H10的910元是节后国内单程含税均价，不能直接相减当作涨价金额。H09还提供记者于9月26日查询的成都—北京10月7日、8日最低裸价样例，它们只是历史快照，不是当前可购买报价，也不是完整价格曲线。

## 5. 节假日扩展顺序与仍需补齐的字段

建议先完善2025国庆中秋，再扩展2024国庆作同季节对照，补2025五一、春节检验不同节日需求结构。该顺序是后续采集安排，不代表本轮已取得这些节日的数据。2025国庆中秋8天与2024国庆7天必须按日均或来源明确的可比口径处理。

| 数据层 | 本轮实际取得 | 仍缺什么 |
|---|---|---|
| 假日历 | 首轮S01可定义2025国庆中秋8天窗口 | 扩展其他假期时另核对官方通知 |
| 航线 | 热门城市对名单、部分航线运力计划 | 完整时刻表、逐日实际班次、座位数、各城市对预订量 |
| 票价 | 全国／市场汇总均价、个别日期与航线的记者查询快照 | 上海至三目的地的完整历史价格面板 |
| 客流 | 全国、上海两场及三目的地机场／枢纽的假期合计 | 城市对日序列、常住地、真实旅游目的 |
| 偏好 | 平台公开汇总主题、目的地名单 | 可对齐到匿名用户的搜索、访问、收藏、购买及营销反馈 |
