# 当前模拟人口：30,000人

2026-10-17按用户要求，将既有72,000名开发用户缩减为26,000名；保留另建的2,000名验证用户与2,000名测试用户，总计30,000名。未入选46,000名旧用户、旧全量SFT副本和旧的逐人实验文件已删除。原始三份Excel、2024航班、冻结需求模型、真实用户数据库及活动记录保留。

## 人口划分

| 用途 | 用户数 | 来源与边界 |
| --- | ---: | --- |
| 训练 | 26,000 | 原始10,000名全部保留，扩展模拟批次分层选16,000名 |
| 验证 | 2,000 | 此前另建的验证用户；可用于开发选择，不参与训练 |
| 测试 | 2,000 | 独立编号与种子，固定保留；不得用于参数选择 |

按来源、原始出发地、年龄、同行方式及前30天平均停留时长分层，比例采用最大余数法，层内按固定种子20261017的哈希排序。筛选不读取未来购票、未来收藏、模型分数或测试表现。训练、验证和测试的用户编号、owner指纹互不重叠。三者仍共享模拟器，不证明真实旅客泛化。

训练行为9,810,000条，总保留行为11,270,000条。原始行为为397天，扩展与新验证/测试均为365天；每个来源保留自己的起止日，不把不同年份或缺失日期强行拼接。出发地沿用用户原始字段。当前网页仍只使用联网航班结果，不以2024价格补缺。

## 核验与后续优化

在应用目录运行：

```powershell
python select_simulated_population.py
python -m unittest test_population_selection test_demand_forecast -v
```

核验工具不再依赖已取消的微调环境。旧候选池已按用户授权清理，重新筛选须重新提供候选资料，不会生成新用户冒充原选择结果。

需求预测采用同一26,000名开发用户，特征截至当天，标签来自后7天；训练使用各来源年度内第180、240、290日。独立验证使用第310、330、350日，独立测试使用第310、330、357日。相对日期用于保留各来源真实起止日，不强行合并不同年份。2,000名测试用户不参与训练、参数或混合权重选择。

新候选已完成训练和最终比较，但稳定提升门槛未通过，继续使用原冻结模型。结果见[评估记录](evaluation.md)。旧版指标只作历史记录。模拟人口不会成为正式营销端真实客群。
