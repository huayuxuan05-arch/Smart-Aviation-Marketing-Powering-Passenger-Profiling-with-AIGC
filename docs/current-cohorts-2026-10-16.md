# 当前航班可查询年度模拟数据与预算偏好方案

版本 `current-queryable-cohorts-v2`。训练10,000人、验证2,000人、独立测试10,000人，各365天，共8,030,000条模拟行为。行为期2025-10-16至2026-10-15。2024原始Excel、10,000名原训练用户与冻结模型保持原样；真实问卷仅作补充，真实活动和个人已保存方案不参与清理。

## 数据准入与隔离

先联网取得完整往返报价，再依据成功查询的出发城市、目的地、日期、天数及中转条件生成模拟用户。6条航线、3个出发日期、2种天数组成36组成功查询；训练、验证、测试各复用12组，用户编号、种子与日期查询组不交叉。同一报价被多人使用，不能计为22,000份独立航班证据。

一年行为独立模拟，不将今天的价格回填到过去截点。年度文件及用户几何条件固定，刷新仅更新报价观测与验收指纹，不修改标签。激活前检查365天、人数、行为文件SHA256、用户/查询组隔离和每名用户的报价条件；报价须在15分钟有效期内，刷新未取得新的成功报价时拒绝重新验收。

**验收时100%有报价是筛选准入条件，不是模型准确率，也不是全体真实旅客的市场覆盖率。** 不保证未来相同请求一直可售；网页对过期报价重新查询，查询期间保留日程，绝不以2024票价填补。样本已受航线可查性筛选，模型效果只能解释为该条件人群表现，不与旧未筛选人群直接比较。

## 推荐策略与结果

每位模拟旅客均生成包含航班、逐日活动、住宿区域、餐饮交通估算与确认清单的方案。动态画像使用本年度近期行为及原冻结需求模型；未声称本轮已完成新权重训练。预算内优先，缺少预算内组合时返回带实际机票报价的超预算备选，保留原预算并展示差额。直飞约束、日期、往返时序、会话归属和报价新鲜度继续检查。超预算候选须本人确认后保存新方案，不自动扩大偏好上限。

覆盖分为方案结果、带报价方案、预算内方案三种。费用枚举的住宿、餐饮、活动及10%预留仍是情景估计，不是实时商户报价。关注评分不是购票概率。

营销旅行方案默认读取本批独立测试用户，画像日期切换到本年度，其他历史营销活动保留。个人入口使用本人偏好，不将模拟用户写入其方案库。网站视觉及双入口不改动。

## 保留策略

航班观测库只持久化成功结果；空结果、失败记录及成功结果内的失败尝试明细均不保留。后台运行状态仅用于当前任务，未成功任务结束即删除；SQLite启用secure_delete。上游与航班接口的诊断日志关闭。旧实验中的航班质量、传输和覆盖报告在当前源码树中退役，不作为本批模型证据。

旧混合批次及旧日志已退出当前数据入口，文件删除由本地执行环境策略阻止，尚需执行仓库的 `scripts/clean_failed_query_files.ps1`。未生成备份，未重写Git历史。

## 文件与复现

- 本地当前数据：`航旅智策应用/runtime/current-cohorts/2026-10-16-v2/`；入口指针：`runtime/current-cohorts/active.json`。
- 各分集：`users.jsonl`、`behavior_arrays.npz`、`behaviors.csv.gz`、`manifest.json`。
- 仅成功报价：`successful-quotes/`；条件设计：`protocol.json`；验收：`acceptance.json`。
- 逐人详细方案：各分集 `traveler_plans.jsonl.gz`；汇总：`plan_report.json`。
- 公开汇总与SHA256索引：[当前数据清单](../distribution/current-cohorts-2026-10-16.json)。大型行为、报价明细、方案和活动数据库不提交，不宣称已发布大型数据Release。

应用目录运行：

```text
python current_cohort_build.py runtime/current-cohorts/2026-10-16-v2 --refresh
python current_cohort_report.py
python -m unittest discover -p "test_*.py" -q
```

初次创建需使用新的版本目录。联网沿用本地已有代理，不调用付费模型。每次刷新后重新导出逐人方案及版本清单；不将刷新前的快照伪称为新查询结果。
