# 参赛思路路线与任务池

当前只做整体框架和实施指南，按[项目怎么做](project-plan.md)执行公开信息与沙盒路线。企业真实数据、渠道接口和真实投放不是当前依赖。

| 周次 | 工作 | 交付门槛 |
|---|---|---|
| 第1周 | 场景 规则 来源试采 | 一页定义 来源台账 时间及用途明确 |
| 第2周 | 聚合需求 标签 客群 | 需求图 标签字典 来源可追溯 |
| 第3周 | 产品匹配 AIGC内容设计 | 约束排序 产品事实卡 内容对照 |
| 第4周 | 渠道时机 反馈与验证 | 闭环方案 回测 盲评 护栏 |
| 第5周 | 管理 财务 报告初稿 | 证据 来源和假设一致 |
| 第6周 | 修订 匿名核查 可选展示 | Word/PDF一致 规则与赛程复核 |

这是建议排期，不是官方截止日期。

| 优先级 | 任务 | 完成定义 |
|---|---|---|

| P0 | 确定节日 地区 目的地范围 | 一页定义与研究问题 |

| P1 | 公开聚合需求面板 | 地区时间目的地主题 可复现处理 |
| P1 | 分群与个人沙盒 | 标签规则 生成假设 两类证据分开 |
| P1 | 产品及内容渠道方案 | 推荐理由 事实约束 人审 频控 |
| P1 | 方法验证与效益 | 回测 对照 盲评 情景 不宣称真实ROI |
| P0 | 报告及匿名检查 | 章节覆盖 脚注 Word/PDF同版 |
