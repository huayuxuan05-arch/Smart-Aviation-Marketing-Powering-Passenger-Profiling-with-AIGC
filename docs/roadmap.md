# 建设路线与任务验收

以下为建议的六阶段顺序，按团队时间调整，不代表官方赛程。框架与数据调研已交付，模型、RAG、平台和实验均待实施。

| 阶段 | 所属层 | 任务与依赖 | 完成标准 |
|---|---|---|---|
| 1 场景与数据 | 数据 | 整理国庆事实，补日序列，建立合成事件规范 | 来源、日期、口径可追溯；覆盖和缺口清楚 |
| 2 算法基线 | 算法 | 需求目标、画像窗口、推荐规则、渠道时机 | 固定样本可复现；输出理由和失败状态 |
| 3 知识与内容 | AIGC | 知识切分、检索、文案、视觉任务书、审核 | 每项事实有引用；无依据不编价格 |
| 4 交互平台 | 应用 | 后端服务、七页面、活动状态、模拟反馈 | 完整流程可交互；合成与真实来源可见 |
| 5 实验评估 | 评估 | 时间切分、基线、消融、盲评、结果登记 | 同口径比较；样本不足保持未评估 |
| 6 报告与展示 | 跨层 | 企业诊断、管理建议、财务情景、展示录制 | 结论对应证据；报告匿名、事实一致 |

## 第一批任务

| ID | 优先级 | 负责人角色 | 具体交付 |
|---|---|---|---|
| D01 | P0 | 数据 | 五类数据字典与公开来源版本 |
| D02 | P0 | 数据 | 日序列可得性清单、合成事件生成设计 |
| M01 | P0 | 算法 | 预测目标与历史基线协议 |
| M02 | P0 | 算法 | 动态画像、候选筛选、规则推荐规格 |
| M03 | P1 | 运营算法 | 渠道时机约束、预算情景与策略对照 |
| G01 | P0 | 知识内容 | 产品事实卡、检索小样本、引用审查 |
| G02 | P1 | 知识内容 | 文案与视觉模型接入、人工盲评 |
| A01 | P0 | 前后端 | 七页面交互与接口实现 |
| E01 | P0 | 评估 | 数据切分、对照、指标与实验记录 |

模型训练依赖D02的有效目标和样本；排序学习依赖曝光与选择记录；真实渠道依赖业务授权和接口。条件不足时完成可解释基线或模拟链路，不用虚构指标填补验收。
