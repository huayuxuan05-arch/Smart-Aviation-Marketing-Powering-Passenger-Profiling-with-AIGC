# AIGC层：需求理解、文案与视觉内容

2026-10-17按用户要求取消9B，统一改用Qwen3.5-4B。当前模拟人口总计30,000人：原始10,000人与分层选取的16,000名扩展用户用于训练，另外2,000人验证、2,000人测试。未入选的46,000名旧用户及72,000人训练副本已删除。出发地使用原始字段，按来源、年龄、同行方式和前30天活跃度分层，不根据未来标签或模型分数筛选。完整数据目录和划分见[当前模拟人口](current-cohorts-2026-10-16.md)。

4B语言模型微调已按用户要求取消，网页直接使用Qwen3.5-4B-Q4_K_M基础量化模型。微调专用BF16权重、PyTorch环境、SFT数据、适配器检查点及缓存已清理；仅保留取消审计和网页必需的推理权重、CUDA运行程序。30,000人模拟数据仅用于独立的需求预测优化，不宣称语言模型已经由这些用户训练。

Start-Local.ps1在存在active_model.json时自动启用本地模型，也可显式指定local-model。模板模式只能作为规则模式使用。模型固定版本、许可和SHA256见[4B清单](../distribution/qwen4b-2026-10-17.json)。

需求支持`required_airlines`与`excluded_airlines`航司代码数组。例如“我不要春秋航空，我要川航的，我想从上海去成都”生成上海→成都、仅3U、排除9C的确认草稿。模型航司建议须能由原文独立核验；保存后真实查询先过滤每段航班再组合排序，预览和保存再次核验。没有符合条件的报价时不使用其他航司补缺；旧方案保留为历史版本。

启动参数提供模板或显式本地模型模式；active_model.json指向Qwen3.5-4B/CUDA。模板模式不启动推理，不能作为大模型效果证据。

需求协商通过`local_generation.extract_preferences`输出field/value/evidence建议，证据必须逐字来自输入，数字、日期、城市和航司由程序核验。`personal_plan_generation.py`以确认条件、训练依据生成逐日行程、住宿区域与条件、四项非机票费用估算、调整方案、旅行建议和行前清单。日期、天数及费用算术由程序控制；模型不返回航班号、机票价或已预订状态。完整草稿缓存到当前偏好版本，确认保存的内容与预览一致；不会在确认时重新采样另一份行程。程序根据已确认城市、日期、人数及航司条件调用实时航班工具。

`planning_evidence.py`读取原10,000名模拟用户的已训练聚类中心、训练期城市关注先验及冻结测试指标。本人主题只匹配聚类内容侧重，不生成伪造的个人行为；城市先验仅在未指定城市时作次级建议。先验只读取最后训练截点之前30天，测试截点只作证据、不进入训练或先验。采用已验证的原模型产物，不启用未通过晋升门槛的实验权重；模拟关注代理不等于购票、航司偏好或实际转化标签。

这是对既有本地航班参考和情景规划工具的受限调用流程，尚无外部实时旅游知识库RAG。规则无法理解任意自然语言；未识别或冲突表述由本人补充或改用表单。

当前下载配置为Qwen3.5-4B-Q4_K_M，NVIDIA运行时为llama.cpp b11565 CUDA；安装入口仅提供4B。固定来源和SHA256见[4B清单](../distribution/qwen4b-2026-10-17.json)，Apache-2.0许可保留于distribution。既有Release不被改写，4B微调已取消，未发布微调产物。

模型根据旅客兴趣主题及结构化事实卡生成文案、配色和抽象插画主题；航班、城市、日期和历史价格由事实槽位合成。JSON 缺字段、截断或模型标识不符时拒绝保存，不静默切换到旧模型。

SVG 代码合成可编辑视觉，页面支持导出。画面属于示意内容，不是景点或酒店实拍，没有扩散图像模型，也没有实时攻略知识库 RAG。

素材保留模型、版本、事实和人工审核记录。事实、历史价格与模拟属性三项核验通过后才可进入模拟触达；修改内容或名单使原审核失效。待审核素材可单独删除，保留活动、其他素材及审计记录。

权重由官方 Qwen 基础模型的 Unsloth GGUF 量化版本提供，未用旅客数据微调。推理、缓存、日志及临时文件均位于 D 盘项目 runtime/local_aigc，不使用云端 API 密钥。
