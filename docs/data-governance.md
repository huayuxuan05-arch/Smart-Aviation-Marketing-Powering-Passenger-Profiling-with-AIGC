# 数据治理与上线验收设计

当前只有虚拟身份与合成行为，没有真实个人信息；以下是企业集成的技术与管理验收设计，不构成已完成的合规认证或法律结论。

## 授权和用途

1. 获得企业数据提供、研究分析、个性化营销与外部模型调用的明确范围，确认是否可用于比赛公开展示。
2. 行为分析授权与营销触达授权分别记录，按用途/渠道校验，未授权、撤回、已购票或达到频控时拒绝营销。
3. 从第一方授权数据开始，不将“公开可见”推定为可以追踪个人，不推断健康、宗教等敏感属性。
4. 不把实名、联系方式或原始个人行为传给外部LLM；只使用经批准的群体标签和产品事实。

## 存储、访问与删除

| 控制 | Demo状态 | 企业验收条件 |
|---|---|---|
| 身份与权限 | 无身份认证，仅本地 | 企业SSO、RBAC、最小权限；操作者和审核者分离 |
| 脱敏 | 全合成ID | 身份映射隔离、加密、访问日志；可识别性复核 |
| 密钥 | 不需要密钥 | 环境或密钥管理服务，日志脱敏，密钥轮换 |
| 生命周期 | 手动换数据库演示 | 约定保留期，过期清理，撤回/删除覆盖画像、任务与导出 |
| 审计 | SQLite行动日志 | 审核身份/时间/依据、不可篡改或防篡改、故障追踪 |
| 模型传输 | 无外部调用 | 供应商/部署区域/保留策略审批，最少信息传输 |
| 投放 | 全模拟 | 幂等、真实滚动频控、静默时间、撤回授权传播、发送前复核 |

`data/raw/`、`data/processed/`、`runtime/`、`output/` 与环境文件被Git忽略；忽略规则不是安全边界，禁止把真实数据写入其他可提交路径。

## 营销与内容护栏

- 真实报价、库存、促销有效期仅能来自批准的产品系统，不由模型生成事实。
- 保留推荐依据及不适配原因；不以未验证画像承诺出行结果，不做不公平的隐性差异定价。
- 退订率、投诉率、频控违规与错误报价属于停止实验的护栏；阈值需企业确认。
- AIGC生成后必须进行事实与品牌审核；模板或模型失败时保持草稿，禁止自动发送。
- 公开Demo和匿名报告不展示真实旅客、企业内部资料或成员/学校/导师信息。

## 上线阻断项

没有授权、身份认证、权限隔离、真实供给接口、内容审核机制、滚动频控、删除策略或反馈归因时，保持本地模拟模式。该清单用于未来企业阶段验收，不要求用户为当前离线框架额外批准。
