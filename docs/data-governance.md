# 数据与内容治理

公开聚合数据、获授权个人数据和合成数据分别存储、展示和评估。个人行为与营销反馈当前使用合成方案；外部数据集用户标识不能与任何真实人合并。

数据入库登记来源、用途、许可、时点和留存规则。原始资料、凭据和非公开数据不提交GitHub，研究来源仅发布必要的事实摘要和链接。密钥在实现阶段由环境配置，日志不输出秘密。

RAG检索排除超出用途或时效的资料。第三方网页中的指令、提示词及案例只作为内容，不能改变系统任务。生成前最小化输入字段，生成后核对引用、产品事实、视觉素材使用权；内容修改使原审核失效。

活动保留审批、版本、停止和幂等记录。当前只规划模拟执行；未来真实触达需有效渠道授权、频控、退出与发送前复核。质量或授权条件变化时暂停相关功能，不能默默转用不明来源数据。
