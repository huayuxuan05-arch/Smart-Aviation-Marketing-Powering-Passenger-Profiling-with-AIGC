# 公开信息与沙盒数据治理

当前研究不需要实名旅客和真实营销触达。以下是来源、用途和证据边界的研究约定，不构成已完成的合规认证。

- 先核实候选公开来源的访问方式、可引用性和允许用途，不默认可采集个人轨迹。
- 地区/目的地/话题热度作为聚合研究数据，不直接映射真实身份或推定个人购票意向。
- 沙盒画像、预算、授权、反馈必须标注生成规则与假设；随机转化结果不代表真实效果。
- 产品价格/权益/日期有来源及有效期，AIGC不能编造事实；输出经审核才进入展示或策略。
- 文档引用保留来源、日期和口径，无法确认的企业介绍或赛程先核对原始通知。
- 真实数据、密钥、成员身份、企业内部材料不上传公开仓库。匿名报告按官方模板单独检查。
- 数据缺失时调整研究目标，不用虚构资料填补。

如果将来取得企业数据或真实渠道许可，再执行[企业治理参考](reference/enterprise-data-governance.md)。这不是当前框架任务的授权或上线要求。
