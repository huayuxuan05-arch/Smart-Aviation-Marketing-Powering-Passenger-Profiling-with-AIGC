data_layer.py 流式读取 Excel，校验固定来源指纹，写入 runtime/aviation.sqlite3；不会将四百万行一次性载入内存。用户编号不连续，不能用行号拼造身份。

特征只使用决策截点前已发生的搜索、访问及收藏子事件；访问未完成时不读取停留时间，未来收藏与取消动作不能回填。预算未知时保留缺失，不解释为收入。统一按北京时间回放历史数据。

历史航班按旅客原始出发城市、目的地、精确日期和已知预算匹配。平均误点中的 1—5 分钟随机填补值不用于真实可靠性排名；历史票价的税费、库存和采集时刻未知，不作为当前可售承诺。

原始工作簿与已训练产物从 Release 校验还原；活动、素材、日志、导出名单和运行数据库不上传。变更来源版本时先调整数据契约和指纹，再重新建立模型与验收证据。

## 当前航班观测

2024原始航班工作簿及SHA256保持不变，供训练和离线评估使用。Web响应层剔除原始历史航班及其报价。当前航班来自固定版本的Farello/fli适配器，逐次显式使用HTTPS代理。flight_observations仅保留有实际报价的批次，按账号隔离；完整去程清单及尚无报价的返程在内存中保留最多15分钟，不作为0元票价历史。catalog按完整航段及起降时间去重，读取全部wrb响应块，包含同城多机场。native_roundtrip先选去程、再查返程；quote_kind为native_roundtrip时total_price_cny是全部所选成人往返总价，单程price_cny保留null，预算不得拆半或重复相加。外币采用ECB最多7天内的参考交叉汇率，缺少可信汇率则不产生人民币报价；金额及汇率元信息供后端审计，不显示在网页。Google预订令牌只在请求期间使用，不进入数据库、导出或网页。成功解析不证明覆盖Google网页全部结果，也不证明最终可售性。

## 真实画像与营销客群

`personal.sqlite3`增加匿名共享同意、确认偏好快照、真实本站交互及真实客群活动表。本人主动开启后才收集共享记录，不自动纳入既有会话、模拟用户或验收数据；原始聊天、会话令牌和owner散列不向营销端返回。撤回同意删除共享快照与交互，并使已保存活动成员及画像、方案访问立即失效；本人私有偏好和方案保持可用。

画像包含自报城市、日期、同行、预算、航司标签和本站确认、保存、模块浏览与操作行为。仅用服务器记录的实际时间，不能回填尚未采集的一月行为。热门目的地按窗口内用户固定编号去重，重复查询不增加人数；属于本站已参与用户热度，不代表全网热度或实名唯一人数。共享画像不等于营销订阅，当前没有发送外部营销或真实订单归因。

## 账号、用户库与浏览证据（2026-10-16）

`personal_users`保存固定匿名编号、创建时间和最近访问时间；`personal_accounts`保存登录名、独立随机盐、PBKDF2-SHA256摘要（600,000轮）及角色；`account_login_sessions`保存令牌摘要及12小时有效期。所有偏好、方案、快照、共享状态和事件关联稳定owner，登录令牌变化不生成另一份画像。迁移旧匿名身份不改变共享状态；注册新账号始终使用新归属，不推定当前浏览器资料属于新注册者。

正式个人接口只接受旅客角色，正式营销接口只接受管理角色。登录使用HttpOnly、SameSite=Strict cookie；本地服务不声称提供公网HTTPS部署。营销端仅输出匿名编号，不输出登录名、散列、令牌、原始聊天或逐字输入。

共享后的 `section_view`记录本人展开的模块；`workspace_action`记录允许的草稿提交、查看历史、预算比较、日期比较和导出动作；`destination_view`记录本站下拉选择目的地。事件白名单和一分钟同类同对象去重由服务器实施，额外客户端文本不保留。已成功保存的偏好才是明确偏好，浏览与草稿尝试只是兴趣线索，不能视为已接受方案。

`flight_search_result`只记录已完成且来源完整的成功/空结果，以及当次航司标签、日期、人数和偏好版本。网络失败不作为无报价结果；空报价只在内存短期返回，不作为票价历史或0元报价。营销端可据此识别有明确航司偏好但待匹配的用户，旧版本查询不会覆盖新偏好状态。匿名案例导出按当前同意重新核验，包含窗口内完整偏好快照和行为；已下载文件需由研究人员自行保管和处理撤回请求。

SerpApi 适配使用 google_flights、deep_search=true、show_hidden=true、no_cache=true；Google地区和报价币种独立于人民币显示币种。完整查询版本包含来源、地区、语言及币种，防止复用其他上下文的报价。先读取best_flights及other_flights，按完整航段和起降时间去重，缺价不丢弃航班；原始响应仅短期内存缓存。选择去程使用与该航班及查询匹配的departure_token，凭据不进入公共响应或数据库。指定往返组合补价使用selected_flights_json，核验返回的两个完整航程与所选一致，只接受实际完整往返金额，不拿单程或部分票价冒充总价。服务请求不含个人账号或画像。密钥使用Windows DPAPI或后端环境变量；本机仅持久化额度计数和已规范化的有效观测，不记录含密钥的请求URL、错误正文、预订提交内容或原始服务响应。
