# 算法层：需求识别、画像与策略

marketing_ml.py 基于全量 10,000 名模拟旅客构建 23 项截点特征，训练需求模型、五群聚类、渠道和时段分类器。报告见[训练报告](../experiments/results/local-demo-2026-10-12/training_report.json)。

需求标签为截点后七天同一目的地至少两次搜索；辅助目标为机票查询及收藏。这些目标是模拟行为代理，不是购票概率。比较 SGD 逻辑回归与直方图梯度提升，按验证 PR-AUC 选模型及 F1 阈值。

标准化和 MiniBatchKMeans 仅拟合训练快照。五类画像配合 algorithm_layer.py 的时间衰减证据，展示主题、目的地、渠道、预算及兴趣变化。所有行为及子事件都按截点遮蔽未来信息。

航线推荐遵守原始常用出发城市、目的地、日期和预算约束；未知计划日期使用明确标注的假期情景假设。无匹配结果时返回原因，不静默更换城市或日期。

渠道及四小时时段模型预测访问习惯，模拟触达限制在 8—22 时，并检查退订及跨活动频次。访问习惯不能直接解释为最优营销转化策略。提前节假日回放使用当时可用的历史基线，避免使用尚未成熟的未来训练模型。
