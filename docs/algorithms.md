# 算法层：需求识别、画像与策略

2026-10-17当前模拟人口统一为30,000人：26,000训练、2,000验证、2,000测试。具体筛选、目录与隔离规则见[当前人口划分](current-cohorts-2026-10-16.md)。新候选已完成训练与独立测试，但未通过稳定提升门槛，继续使用冻结基线。下文原10,000人及旧版指标保留为历史记录；本次结果见评估层。

marketing_ml.py 基于全量 10,000 名模拟旅客构建 23 项截点特征，训练需求模型、五群聚类、渠道和时段分类器。报告见[训练报告](../experiments/results/local-demo-2026-10-12/training_report.json)。

需求标签为截点后七天同一目的地至少两次搜索；辅助目标为机票查询及收藏。这些目标是模拟行为代理，不是购票概率。比较 SGD 逻辑回归与直方图梯度提升，按验证 PR-AUC 选模型及 F1 阈值。

标准化和 MiniBatchKMeans 仅拟合训练快照。五类画像配合 algorithm_layer.py 的时间衰减证据，展示主题、目的地、渠道、预算及兴趣变化。所有行为及子事件都按截点遮蔽未来信息。

decision_logic.py在最多3个有近期行为依据且达到关注门槛的目的地中，优先选择明确计划、本次预算和历史产品条件均满足的候选，其次保留有历史候选或兴趣首选。用户指定目的地时不扩展。出发城市保持原始字段，各目的地保留自己的计划日期，不静默放宽约束。

预算只采用最近30天同目的地、同明确计划日期最近一次机票查询上限，其他预算作为参考，缺失时保持未知。最新未来计划在假期之外时明确暂缓，不回用旧假期计划。未知日期仍展示标明的情景日期，但不因此取得执行资格。模型特征与权重未改变；该层调整的是业务决策及约束语义。

渠道及四小时时段模型预测访问习惯，模拟触达限制在 8—22 时，并检查退订及跨活动频次。访问习惯不能直接解释为最优营销转化策略。提前节假日回放使用当时可用的历史基线，避免使用尚未成熟的未来训练模型。

个人旅客入口使用主动填写的偏好与独立版本快照，不向该旅客套用模拟user_id或购票概率。复用原始历史航线网络和详细旅行方案组装；不会将个人端自报选择混入既有模型训练标签。


2026-10-15一手问卷整理与升级：见 [问卷证据、约束推荐及验证](survey-evidence.md)。真实答卷仅本机保存；新增问卷影子模型未通过稳定提升门槛，线上采用用户约束与透明样本先验，保持原模拟模型独立。

## 个人方案的当前航班约束

自主标签通过`required_airlines`、`excluded_airlines`、日期弹性和`flight_budget_policy`落入查询键。航司条件同时发送到供应源并在组合前、持久化前、预览和保存时核验。`flight_ranking.py`采用字典序：航司符合要求、日期偏差、预算符合情况与票价、中转次数、总耗时。固定日期不扩展；允许前后1/3天时平移往返日期并保持旅行天数，预览列出实际日期，本人确认后才保存。预算优先保留超预算备选并标记；只看预算内则滤除超限，预算未知不能选择严格预算标签。客户端保留服务端排序，不重新把低价摆到航司/日期之前。

正式营销客群使用`real_travelers.py`的确认偏好、真实交互时间窗和可解释意向阶段，不套用模拟身份或输出购票概率。聚类内容先验读取已训练产物；新的真实数据尚无订票/转化标签时不宣称分类器已在真实用户上通过验证。热门榜按7/30/90天旅客去重、与前7天变化比较。撤回共享从候选和活动名单中立即移除。

个人目的地建议保留主动偏好与训练所得先验，不再以2024航班可达性或票价决定当前旅行产品。航空费用必须来自当前查询，旧价不补缺。报价与城市、出行日期、人数和中转约束一致且有效时才能进入预算；往返两段时序须可行。查询价按人数均摊，住宿餐饮估算保持独立。模型说明不新增航班事实。
